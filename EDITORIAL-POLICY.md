# Editorial workflow

Prepare seven Persian patient education articles each Friday for Dr Pedram Amiri. Use verified medical sources and real images with documented reuse permission. Do not generate images or claim external clinical photographs show Dr Amiri's patients.

All incoming articles require explicit approval before publication on drpedramamiri.com. Approval must apply to the exact content revision. Schedule approved articles one per day in Asia/Tehran. Preserve manual edits. Do not publish drafts automatically.

The GitHub connection does not itself activate website synchronization. Website import and batch approval must be installed and tested before claiming that publication is active.

No paid AI API is part of this workflow.
